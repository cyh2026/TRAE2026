用户服务协议

最近更新：2026-08-11（应用版本 1.5.7）

欢迎使用「车辆助理」（以下简称"本应用"）。在使用本应用前，请您务必仔细阅读并充分理解本协议的全部内容，尤其是涉及责任限制与个人信息保护的条款。如您不同意本协议任意内容，请勿注册或使用本应用。

一、协议范围

本协议是您与本应用运营方之间关于使用本应用所订立的协议。您点击"同意"并完成注册，即视为您已阅读、理解并同意接受本协议全部约束。

二、账号注册与使用

  • 您需使用手机号作为账号唯一标识完成注册，并设置登录密码。
  • 您承诺所提供的手机号为您本人真实、合法拥有的号码，并保证账号信息的真实性、合法性。
  • 您应妥善保管账号及密码，因账号保管不善或密码泄露导致的损失由您自行承担。
  • 本应用为纯本地应用，您的账号与数据仅存储于您本机设备，不会上传任何远程服务器。

三、用户行为规范

您不得利用本应用从事任何违反法律法规、侵犯他人合法权益或干扰本应用正常运行的行为；不得尝试逆向工程、破解或篡改本应用。

四、数据权属与备份

您在本应用中录入的车辆养护、油耗、故障记录等业务数据归您本人所有。您可通过"我的 → 数据导出"将全部数据导出备份，也可通过"数据导入"恢复，便于更换设备时迁移。

五、免责声明

本应用提供的保养建议、故障排查、道路救援等信息仅供参考，不构成专业维修或医疗建议。涉及车辆安全与维修，请以专业机构意见为准；本应用不对依据应用信息作出的决策及其后果承担责任。

六、协议变更

我们可能适时修订本协议。变更后将在本应用中重新征得您的同意；若您继续使用本应用，即视为接受修订后的协议。

七、联系我们

如对本协议有疑问，可通过应用内"我的 → 关于"页反馈，或发送邮件至 cyh2299@hotmail.com 与我们联系。

隐私政策

最近更新：2026-08-11（应用版本 1.5.7）

我们高度重视并保护您的个人信息。本政策向您说明：本应用会收集哪些信息、为何收集、如何收集、如何使用与存储，以及您所享有的权利。在您使用本应用前，请务必阅读并同意本政策。我们仅在取得您授权同意后，才会收集您的手机号等个人信息。

一、我们收集的信息

  • 手机号：作为您的账号唯一标识，用于注册与登录的身份识别。
  • 密码：用于本地登录验证；在您勾选"记住我"或开启生物识别登录时，以明文形式存储于本机，用于自动填充与解锁。
  • 业务数据：您主动录入的车辆信息、保养记录、油耗、故障记录等，用于向您提供养护管理服务。

二、收集的目的与方式

  • 目的：提供账号注册/登录、识别用户身份、在您本机管理并备份恢复您的车辆养护数据。
  • 方式：手机号与密码由您在注册/登录时主动输入；验证码仅在您点击"发送验证码"时于本机生成并提示（演示环境），不会外发；业务数据由您主动录入。

三、信息的使用与存储

  • 纯本地存储：本应用不连接任何远程服务器、不上传任何数据。上述所有信息仅存储于您本机设备的应用本地存储（localStorage）中。
  • 密码说明：为支持"记住我"与生物识别解锁，密码以明文保存于本机。请您知悉该本地存储方式的安全边界，建议为设备设置锁屏密码。
  • 临时权限：道路救援功能可能在您授权后临时获取定位，定位仅在本机用于呼叫救援，不会上传。

四、信息共享

我们不会向任何第三方共享、出售或提供您的手机号、密码或业务数据。本应用不存在将数据传输至外部服务器的行为。

五、您的权利

  • 查询与导出：可通过"我的 → 数据导出"导出全部数据。
  • 更正与删除：可随时修改业务数据；可通过"退出登录 / 清除缓存 / 卸载应用"删除本地账号与数据。
  • 撤回同意：您可在"我的 → 隐私与权限"中撤回同意，撤回后我们将清除本地账号与全部数据，应用停止收集信息。
  • 未成年人：若您未满 18 周岁，请在监护人同意下使用本应用。

六、政策变更

本政策随应用版本更新。政策变更后，我们将再次向您征得同意；您继续使用时即视为接受变更后的政策。

七、联系我们

如对本政策有疑问，可发送邮件至 cyh2299@hotmail.com 与我们联系。
